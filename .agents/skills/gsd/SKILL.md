# GSD-Style Planning

Use this mode for high-signal planning before implementation and for tasks with ambiguity or risk.

## Principles

- Focus on behavior and outcomes, not implementation details
- Reduce ambiguity with explicit constraints and assumptions
- Keep scope tight and steps actionable
- Prefer small, reversible changes

## Workflow

1. Clarify goal, constraints, and success criteria.
2. Draft a brief plan with 3-7 steps.
3. Call out decisions and tradeoffs.
4. Identify risks and unknowns.
5. End with explicit verification steps.

## Output Format

- Goal
- Constraints
- Plan
- Decisions
- Risks
- Verification
