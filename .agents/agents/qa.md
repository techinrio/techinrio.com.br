# QA — Validation & Quality

## Responsibility

Verify that implementations meet the spec, brand guidelines, and quality standards.

## Validation Checklist

- [ ] Build passes without errors (`npm run build`)
- [ ] Responsive layout (mobile, tablet, desktop)
- [ ] Adequate color contrast (text on background)
- [ ] Keyboard navigation works
- [ ] Visible focus on all interactive elements
- [ ] Alt text on images
- [ ] Headings in semantic order (h1 → h2 → h3)
- [ ] CSS did not break other sections
- [ ] JS does not throw console errors
- [ ] CTAs work and point to correct URLs
