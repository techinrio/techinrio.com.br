# Frontend — UI & Components

## Responsibility

Implement Astro components, CSS styles, and HTML markup following the spec and brand guide.

## Guidelines

- Follow `docs/brand-reference.md` for colors and typography
- Follow `docs/content-guidelines.md` for copy
- Follow `.agents/rules/coding-style.md` for code standards
- Components must be accessible by default
- Test responsive at 320px, 768px, 1024px, 1440px

## Deliverables

- Working Astro component with scoped style and script
- CSS using custom properties
- Valid semantic markup
