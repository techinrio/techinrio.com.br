# AI Working Style

- Read relevant documentation in `docs/` before starting any task
- Check rules in `.agents/rules/` before modifying code
- Prefer small, reversible changes
- Consult `docs/spec.md` for product decisions
- Consult `docs/brand-reference.md` for visual decisions
- Consult `docs/content-guidelines.md` for copy decisions
- Validate with `npm run build` when done
- Commits must follow `.agents/rules/git-workflow.md`
