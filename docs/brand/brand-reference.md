# Tech In Rio — Referência de Marca

## Fonte Oficial

O arquivo oficial de marca é o `Manual ID Visual - Tech In Rio.pdf` disponível em `Tech In Rio Public Assets/`. Este documento consolida as definições para referência rápida no desenvolvimento.

## Regras Visuais

- laranja como cor de acento, não como cor dominante em tudo
- usar muito espaço em branco ou áreas de respiro visual
- preservar contraste alto para leitura (texto claro sobre fundo escuro)
- evitar excesso de decoração, sombra e brilho
- usar imagem apenas quando ela acrescentar contexto real

## Tipografia

- **Font stack**: `Inter`, system-ui, -apple-system, sans-serif
- **Mono**: `JetBrains Mono`, monospace (para detalhes técnicos, tags, labels)
- Priorizar legibilidade em tamanhos pequenos e mobile
- Reservar destaque tipográfico para títulos e chamadas institucionais

## Padrões de Layout

- hero forte e direto
- blocos de conteúdo curtos e bem separados
- chamadas de ação claras
- composição responsiva
- navegação simples e previsível
