# Tech In Rio — Landing Page

Site institucional da Tech In Rio, a comunidade de tecnologia mais carioca de todo Brasil!

## Stack

- [Astro](https://astro.build) 7 — geração estática
- CSS puro com custom properties
- JavaScript vanilla (mínimo no cliente)

## Comandos

| Comando | Ação |
|---------|------|
| `yarn dev` | Inicia servidor local em `localhost:4321` |
| `yarn build` | Gera build estático em `dist/` |
| `yarn preview` | Preview do build local |

## Estrutura

```
src/
├── assets/       — imagens e recursos estáticos compilados
├── components/   — seções e blocos da página
├── data/         — dados estáticos (canais, CTAs) e membros em `data/comunidade/`
├── layouts/      — estrutura base das páginas
└── pages/        — rotas do site (`/`, `/comunidade/`)

docs/             — especificação, marca e diretrizes
.agents/          — orientações para desenvolvimento com IA
public/           — assets estáticos (favicon, logos, og-image)
```

## Documentação
